# ADR-0001: 디자인 헌법을 apple-design.md로 교체하고 화면·모션을 재정초한다

- 상태: 채택 (2026-08-11)
- 결정자: nineking424 (그릴 세션에서 결정 확정)

## 배경

초기 UI는 DESIGN.md(파치먼트 단일 화면, 그림자 금지, 단일 액센트, 정적 필 버튼)를
헌법으로 구축되었다. 소유자는 이 프로젝트를 취미·실험 영역으로 규정하고, 경제적
논리보다 실험적 도전을 우선한다는 원칙 아래 DESIGN.md를 폐기했다. 새 헌법은
루트의 `apple-design.md`(Apple WWDC 디자인 원칙의 웹 번역판)이다.

## 결정

1. **범위 — 전면 재정초.** 비주얼과 모션을 모두 apple-design.md 기반으로 재설계한다.
   기능 로직(회전·검증·파일명 규칙)과 상태 경로는 불변.
2. **무대 — 콘텐츠가 주인공.** 파일 열림 후 미리보기가 화면을 지배하고, 컨트롤은
   하단에 떠 있는 반투명 재질 툴바(backdrop-filter)로 응축된다(§12). 종이 하단은
   툴바 아래로 지나가 재질의 존재 이유를 만든다.
3. **인터랙션 — 직접 조작.** 미리보기 페이지를 원호 드래그로 비틀어 회전한다:
   1:1 추적(§2) → 릴리스 각속도 투사 `project()`(§6) → 최근접 90° 디텐트로 속도
   인계 스냅(§5) → 스냅 중 재개입 가능(§3). 버튼은 접근성·정밀 조작용으로 병존하며,
   제스처와 버튼은 동일한 상태 경로(`accumulatedDelta`)로 합류한다.
4. **모션 엔진 — 자작.** 외부 라이브러리 없이 감쇠 조화 진동자 폐형식 해를
   구현한다(`springStep`). Apple 파라미터(damping ratio / response)를 원어 그대로
   사용한다: 회전 0.8/0.4, 툴바 1.0/0.35(§4). 순수 함수로 두어 verify.mjs가
   수렴·재타기팅 연속성을 수치로 검증한다.
5. **컬러 — 시스템 추종.** `prefers-color-scheme`로 라이트/다크 자동 전환.
   수동 토글은 만들지 않는다(§16 Simplicity). 검증을 위해 `data-theme` 강제
   훅만 둔다.
6. **접근성 — §14 전면 수용.** `prefers-reduced-motion`(스프링 생략·즉시 반영),
   `prefers-reduced-transparency`(재질 불투명화), `prefers-contrast`(경계 강화).

## 결정의 세부 트레이드오프

- **제스처 판별**: 미리보기 스트립의 가로 스크롤과 회전 드래그가 충돌한다.
  세로 우세 드래그와 페이지 상·하단 밴드의 가로 드래그는 회전, 중앙 밴드의
  가로 드래그는 스크롤로 판별한다(`classifyDrag`, 10px 히스테리시스 — §10).
  터치 기기에서는 `touch-action: pan-x`로 가로 스크롤을 네이티브에 맡기고
  세로 원호만 회전으로 받는다.
- **크리스프 렌더 전략**: 캔버스는 90° 디텐트에서만 pdf.js로 재렌더하고, 그 사이
  프레임은 CSS transform(rotate+scale)과 프레임 폭 보간으로 표현한다. 스프링
  안착 시각 크기와 크리스프 렌더 크기를 일치시켜 스왑 점프를 없앤다.
- **검증**: 수치 층(verify.mjs — CORE 추출·스프링 물리·판별기)과 시각 층
  (헤드리스 Chrome 스크린샷·CDP 스크린캐스트 프레임 시퀀스를 서브에이전트가
  apple-design.md 기준으로 심사) 이원화. 헤드리스 가상 시간은 pdf.js 워커와
  스프링 실시간 특성을 왜곡하므로 puppeteer-core 실시간 구동을 사용한다.

## 결과

- DESIGN.md 삭제 (git 이력이 아카이브), apple-design.md 커밋.
- index.html 표현 계층(CSS·모션 JS) 전면 교체, CORE 로직 유지.
- verify.mjs를 저장소에 신설 — 이후 변경은 이 하니스 통과가 전제다.
- CONTEXT.md 용어 갱신 (뷰어 모드·툴바·원호 드래그·누적 회전과 연속 각도의 관계).
